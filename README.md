# Giro-de-Estoque
Sistema de análise pontual e gestão de giro de estoque para SKUs da Venda Direta (O Boticário), desenvolvido em Python.

Funcionalidades
- Cálculo de Giro de Estoque: Automação do cálculo de rotatividade por SKU, eliminando processos manuais e reduzindo erros.

- Monitoramento de Transferências: Consolidação de dados de movimentação entre unidades para facilitar o controle logístico.

- Logs em Excel: Exportação detalhada dos SKUs analisados em formato .xlsx, garantindo o registro histórico e a rastreabilidade de todas as consultas realizadas.

- Interface Funcional: Desenvolvida para otimizar o fluxo de trabalho operacional, com foco em usabilidade e rapidez na consulta.
